Sales & Profit Dashboard in Microsoft Excel

An interactive Sales & Profit Dashboard built in Microsoft Excel to analyze business performance using Pivot Tables, Pivot Charts, Slicers, and Map Charts. This project transforms raw sales data into meaningful visualizations, enabling users to monitor sales, profit, customer performance, product categories, and state-wise trends through an intuitive dashboard.

 
 Project Overview

This project demonstrates how Microsoft Excel can be used as a Business Intelligence (BI) tool to create an interactive dashboard without using advanced programming languages.

The dashboard allows users to filter data dynamically by Category, Year, and Month, making it easy to explore business performance and gain actionable insights.
